How this run verified things

Two independent MLS-fed sources, not search results

The earlier version of this page reported four properties that turned out to be off market, because listing status was inferred from search-engine text. That channel is no longer used. This run reads 303 live listings straight from a MetroList IDX feed with per-listing structured MLS fields — status, bed and bath counts, lot acreage and pool construction details — and reads 58 full detail pages for the shortlist.

Each board listing is then cross-checked against a second, independently operated feed. 6 of 10 matched exactly on price, beds, baths and acreage. The remainder aren't indexed by the second source; their cards say so, and those are the ones to confirm by phone first.

Negative control: All six properties carried from the previous run were re-checked against the live feed. The five the user confirmed off market are absent from it; the one that was genuinely active (1601 Velvet Horn Ln) appears at the same price and MLS number.

Pool status comes from the MLS Pool and Pool Description fields, not from listing prose — so “room for a pool” can't be misread as a pool. Acreage comes from the MLS lot-size field rather than the marketing copy.
