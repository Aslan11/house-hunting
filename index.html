How this list is built

Listings come from the Redfin GIS/CSV export for ZIPs 95667, 95672 and 95682, filtered to status=Active. That export is MetroList MLS data, not a search-engine summary, so listing status is live rather than cached. Every property that passed the bed/bath/price/acreage filter then had its own listing page fetched and parsed for the structured `hasPrivatePool` flag and the MLS Pool Information block — the pool requirement is verified per-listing, never inferred from marketing copy.

Caveats

Redfin's export carries a standard disclaimer that some MLS listings are withheld from download under local MLS rules, so this is a very good sample of inventory rather than a guaranteed-complete one. Cross-checking against a second portal was not possible this run — Zillow, Realtor.com, Homes.com, Trulia and Movoto all refuse requests from this environment's IP range. Acreage is the MLS lot-size field and is sometimes rounded. Confirm anything that matters with the listing agent before acting on it.
