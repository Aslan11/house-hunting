How this list is built

First run with live MLS access. Outbound HTTPS opened up this run, so the MetroList IDX feed at cherielliott.com (a Sierra Interactive site, feed timestamped 2026-10-26 06:30) and MLSListings.com MetroList records became readable. Every match below had its Pool-or-Spa field, lot acreage, bed/bath count and Active status read off a live record. The six properties replace the 2026-07-26 run's four false positives, all of which the user confirmed were off market.

The rule this tracker runs on: a property is only shown as a match once its status is confirmed against a live listing page or MLS record. Search-engine results are used to discover candidates and never to confirm them — search engines index sold listings with “For Sale” in the title for years, which is exactly how the 2026-07-26 run produced four properties that were all off market.
