How this run was verified

This run reached MetroList MLS directly — the MLS that actually covers El Dorado County — through its official public search site. That matters because the MLS reports acreage and pool as structured fields (Lot Size in Acres, Has a Pool), so neither is inferred from marketing text, and a listing's status is read off its own live page rather than a search-engine summary.

The method was checked against known answers before being trusted: the MLS numbers for all six properties this page tracked in July return “Listing Not Found”, which matches the report that every one of them was off market. Active listings return a page reading FOR SALE.

A broker IDX site (century21.com) was cross-checked for coverage and omitted all six qualifying Placerville properties — so broker sites are not reliable on their own for this search. 6 of 6 cards carry MLS photos, hotlinked from the MLS media server and loaded by your browser.

Reading the market

The earlier read still holds, and this run finally has the data to state it precisely: the pool is the binding constraint, not the budget. Of 183 active listings across the three towns, only 13 pair a pool with 2.5+ acres inside budget, and 6 of those clear 4+ beds and 3+ full baths. Placerville carries the inventory almost single-handedly. Shingle Springs has nothing — its one pool-and-acreage property in budget, 7060 Steeple Chase Dr, is a 3-bedroom. Rescue has exactly one qualifying home. If location inside the three towns is flexible, Placerville is where to look; if Shingle Springs matters, expect to wait for new inventory or to raise the ceiling.
