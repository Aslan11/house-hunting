How this page is built

Redfin became reachable from this environment on the 2026-07-26 run (www.redfin.com returns 200; Zillow, Realtor.com, Homes.com, Movoto and Trulia are still blocked). Search results are read from the server-rendered /stingray/api/gis payload embedded in each filtered search page, and every candidate is then confirmed against its own live detail page. Pool status comes from the MLS POOL_PRIVATE_YN field on that page, not from listing prose - which is what caught 4810 Robledo Dr, 1200 W El Largo Dr and 3961 Seven Ridges Rd, all of which mention pools in text but report hasPrivatePool=false.
