How this page is built

Source and verification

Listings read from the MetroList IDX feed rendered by coldwellbankerhomes.com. Beds, baths, price, lot acreage, pool and Status come from the MLS record on each listing's own detail page — not from search-engine text. Only records showing Status: Active are presented as matches.

The MLS Pool field is published as "Yes" or omitted entirely; it is never "No". A listing with no Pool field is treated as unknown and excluded from matches, so the board under-reports rather than over-reports.

This run scanned 305 listings across the three towns, of which 74 cleared the bedroom and price screen and had their full MLS record pulled. Every property shown above was confirmed Status: Active on its own listing page at build time.

An earlier version of this tracker reported matches inferred from search-engine snippets, and all of them turned out to be off market. That is why status now comes only from the live MLS record, and why a listing whose pool field is missing is excluded rather than assumed.
