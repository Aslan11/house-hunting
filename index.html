How this list was built

  1. Full inventory pull. Every active listing in ZIPs 95682 (Shingle Springs), 95672 (Rescue) and 95667 (Placerville) was read from the Compass MLS feed — 406 listings, not a search-engine sample.
  2. Hard filters. 4+ bd, 3+ ba, 2.5+ acres, at or under $1,500,000 → 22 candidates.
  3. Pool evidence. Each candidate's MLS remarks were read in full. Phrases like “room to add a pool” were excluded — that removed one property that a naive keyword match would have called a match.
  4. Independent status check. Every surviving property was re-checked by MLS number on MLSListings.com. That confirmed all 9 as Active, and corrected two bath counts that the first source had rounded up.

Known limits. Pool presence comes from listing remarks, so a pool that goes unmentioned would be missed. Bath counts follow the MLS convention “full/half”. Shingle Springs returned no match at any price under $1.5M this run — its closest candidates are in the ruled-out table.
